# Skill: Navigation
Basic movement through the web.

### 1. CLICK
- **Payload**: `{"action": "CLICK", "target": "backendId"}`
- **Usage**: Use for buttons, links, and checkboxes.

### 2. SCROLL
- **Payload**: `{"action": "SCROLL", "text": "up"}` or `{"action": "SCROLL", "text": "down"}`
- **Usage**: Use when content or elements are hidden off-screen.

### 3. NAVIGATE
- **Payload**: `{"action": "NAVIGATE", "text": "url"}`
- **Usage**: Jump directly to a page if you cannot find a link.
